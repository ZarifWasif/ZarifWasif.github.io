# zarifwasif.github.io

Personal research site. Static — one HTML file and three images, no build step.

    index.html
    img/portrait.jpg
    img/defence.jpg
    img/convocation.jpg

## Publish on GitHub Pages
1. Create a repo named `zarifwasif.github.io` (public).
2. Upload these files to the root of the `main` branch.
3. Settings -> Pages -> Source: `main`, folder `/ (root)` -> Save.
4. Live at https://zarifwasif.github.io within a minute or two.

## Publish on Netlify
Drag this whole folder onto https://app.netlify.com/drop — it deploys instantly.

## Custom domain
Point a domain at either host from their DNS settings; both support HTTPS for free.
